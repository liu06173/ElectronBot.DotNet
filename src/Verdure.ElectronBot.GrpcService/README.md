## Verdure.ElectronBot.GrpcService Project

This project is a web service written in .NET, primarily hosting a gRPC service. It is deployed on a Raspberry Pi, interoperating with libusb to receive and write facial expression data transmitted by the Electronic Braincase to the Electron hardware for display.
